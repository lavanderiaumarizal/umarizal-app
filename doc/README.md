# 📱 Umarizal App — Aplicativo de Logística Interna

Substitui a planilha manual de controle de entrada/saída de tapetes e gerencia as 4 fases e 12 etapas do Padrão Umarizal.

**Tecnologia:** React Native (Expo) + EAS Build local
**Público:** Motoristas, Lavagem, Secagem, Expedição (back office)
**Repositório:** `umarizal.app` — [GitHub](https://github.com/lavanderiaumarizal/umarizal-app)
